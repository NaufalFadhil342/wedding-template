# Event & Wedding Invitation

MarWed is a single page application establishing for online invitation. It use for **wedding invitation, family gathering, birthday party, bazaar event, and others**. The website is responsive with a clean design. Following the modern website pattern, elements part of the website has already interactive.

## Features
- **Home**: The top section of this website
- **Couple**: The groom & bride bio section
- **Story**: The section of their journey
- **Where&When**: The section contains date, time and place
- **People**: Contains the family, friends of the couple
- **Events**: Contains events exist at the wedding
- **Gallery**: Contains photo album of the couple
- **RSVP**: The form consists announcement for you to attend or no

## Tech Stack
- Reactjs
- React Router Dom
- React Scroll
- React Icons
- Embla Carousel

## Installation
1. Download ZIP file
2. Extract file and choose your directory
3. Open terminal such as CMD, Shell, or Git Bash
4. Install dependencies:
  ```
  npm install
  // or
  yarn add
  ```
5. Run the program:
  ```
  npm start
  // or
  yarn start
  ```
6. Open the browser and type or copy `http://localhost:3000`
7. The program is ready to use

## Production
You might consider your project can use globally, follow the step:
1. Consider what is hosting you'd like to use
2. You can push the project to your GitHub or Github account
3. If you want to push the project direct to your hosting, you must run:
   ```
   npm run build
   // or
   yarn build
   ```
4. Wait 'til the program finish and the result might `dist` or `build`
5. Copy or drag the `dist` or `build` to your hosting
6. Congrats, your website can use globally
